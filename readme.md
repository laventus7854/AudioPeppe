# 🎧 Audio Diagnostics

Одностраничное веб-приложение для всесторонней диагностики аудиоустройств
(наушники, динамики, микрофоны, звуковые карты) — **полностью в браузере**.
Без установки, без регистрации, без передачи данных на сервер.

🔗 **Демо**: `https://<username>.github.io/audio-diagnostics/`

---

## ✨ Возможности

### Каналы и стерео
- Тест левого / правого канала (тон 440 Гц)
- Одновременная подача L+R для проверки баланса
- Стерео-панорамирование (Pan Sweep L → R за 4 с)
- Пинг-понг L/R с настраиваемым интервалом
- Измерение перекрёстных помех (Crosstalk) через микрофон
- Определение Bluetooth-задержки (round-trip)

### Частотные тесты
- Полный свип 20 Гц → 20 кГц (логарифмический)
- Свип низов 200 → 20 Гц
- Свип сабвуфера 100 → 20 Гц
- Отдельные тона 8, 10, 12, 15, 16, 18, 20 кГц
- Ручной генератор: частота 20 Гц–20 кГц, 4 типа волны, выбор канала
- Автопоиск «мёртвых зон» (провалы АЧХ)
- Автопоиск резонансов (пики АЧХ)

### Фаза и полярность
- In-Phase / Out-of-Phase сигнал
- Инверсия полярности правого канала
- Тест фазировки наушников (поочерёдные импульсы)

### Наушники
- Относительная АЧХ через loopback-микрофон (график)
- THD (Total Harmonic Distortion) — реальный FFT на 5 гармониках
- Тест «пробитого» динамика (треск, хрип)
- Тест комфорта громкости (шаг 1 дБ)
- Измерение собственного шума (noise floor) наушников

### Динамики / 5.1 / 7.1
- Поочерёдная подача по каналам: FL, C, FR, SL, SR, LFE
- Проверка кроссовера (60/100/150/200/300 Гц)
- Тест «сцены» — 8 позиций по кругу

### Микрофон
- VU-метр с индикатором клиппинга
- Запись + воспроизведение + скачивание WAV
- Управление Echo / Noise Suppression / AGC
- Round-trip latency (кросс-корреляция)
- Тест на эхо и отражения

### Измерения
- Спектроанализатор (FFT, живой)
- Уровнеметр (дБ SPL, относительный)
- Калибровка 0 дБ
- Noise floor (средний / минимум)
- Тест «возраста слуха» (8 → 20 кГц)
- Динамический диапазон
- Wow & Flutter (девиация 3150 Гц)

### Инструменты
- DTMF-генератор (телефонные линии)
- Генератор белого / розового / коричневого шума

### Отчёты
- Автоматическая оценка 0–100
- Список проблем и рекомендации
- Экспорт в JSON
- Поделиться ссылкой (URL hash)
- История в `localStorage`
